# Targets — user guide

## First time
1. Switch on the hub. Its WiFi network **Airsoft-Master** appears after a few seconds.
2. Join it from your phone. The app opens by itself; if not, open **http://192.168.4.1**. If the phone says the network has no internet, choose **Stay connected**.
3. The setup wizard asks for a name and an optional WiFi password, then for your targets.
4. Switch on the targets. A target's light **breathes white** while it looks for the hub and turns **dim blue** when connected. New targets join automatically.
5. Shoot or tap each target once to test it. Done.

## Target lights
| Light | Meaning |
|---|---|
| Breathing white | Looking for the hub |
| Blinking amber | Found a hub, waiting to be added (Targets screen → Add) |
| Dim blue | Connected and ready |
| Pulsing blue | Connected, battery under 10% |
| Off | Between games (standby, 10 s) |
| Blinking white | "Blink" pressed in the app (find this target) |
| Green flash on each hit | Sensor test |
| Pulsing magenta | Firmware update running: don't switch off |

## Playing
Play → pick a player (or Guest) → pick a game → choose a preset or adjust the settings → **START**. Targets blink yellow three times, flash green, then the game starts. During a game the screen shows time, score and a live copy of the target lights. **Hold to stop** ends the game early (it isn't saved).

- **Time Attack+**: shoot the red targets fast. Faster = more points; streaks from the 4th hit give ×1.5. A dark target costs 15 points and freezes everything orange for a second.
- **The Breach**: watch the blue sequence, then hit the targets in the same order. 10 levels.
- **Shoot / No-Shoot** (2+ targets): red = shoot before it goes dark, green = hostage, don't shoot.
- **Free Practice**: one target at a time, shows every reaction time, nothing saved.

## Targets screen
Hit a target and its card flashes, so you know which is which. Tap a card to rename it, change its number (swaps with the other target), tune the hit sensor, calibrate the battery with a multimeter reading, blink it, restart it or remove it. **Sensor test** shows every hit live: use it to set the lockout (fewer double hits) and pulses (ignore light knocks).

## Settings
WiFi name, channel and optional password · LED brightness · auto-add new targets · maximum targets · sounds and dark/light theme (light is easier in sunlight) · **simulated targets** to try games with more targets than you have · firmware updates · **Download backup / Restore backup** · factory reset.

Keep a backup after a good session: Settings → Data → Download backup.
